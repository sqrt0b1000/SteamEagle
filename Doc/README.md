# The HTML Content Types

The standard `HTML` content types
are referred as contexts.

> [!NOTE] Fix naming mess!

- `Context` -> context / content shared by all types
  - `DocumentBodyContext` -> Flow
  - `InlineContext` -> Phrasing
  - `InteractiveContext` -> Interactive (not used yet!)
  - `HeaderContent` -> Heading (not used yet!)
  - `SectionContext` -> Sectioning (not used yet!)
  - `EmbeddedContext` -> Embedded (not used yet!)
  - `Attribute` -> Metadata
    - Each Attribute has its own `Context Type`
